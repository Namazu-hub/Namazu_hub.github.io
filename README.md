# ATLAS — Earth in Motion

CesiumJS を使った、都市と大自然を繰り返し巡る **シネマティックな地球ライブ壁紙**です。Lively Wallpaper / Windows / 通常のブラウザに対応します。

## 使い方

### Web から（推奨）

GitHub Pages などの静的ホスティングで `index.html` を公開し、Lively Wallpaper の **「壁紙を追加」→「URLを入力」** に次の URL を指定します。

```
https://namazu-hub.github.io/Namazu_hub.github.io/?wallpaper=1
```

`?wallpaper=1` では操作ボタンを隠し、マウスでの地球操作を無効にします。シーンは自動で続きます。

### ローカルで

フォルダ内で `python -m http.server 8000` を実行し、`http://localhost:8000/?wallpaper=1` を開いてください。ブラウザから `file://` で直接開くより HTTP サーバーを推奨します。インターネットへの接続は衛星画像と CesiumJS の読み込みに必要です。

## 再生仕様

**v4：写真ベース3D・長めの鑑賞・地点単位の進行バー**。目的地の上空に到着してからズームインする動きを維持し、近景の鑑賞時間を標準速度で **15秒から40秒** に延長しました。周回速度も毎秒4.5度から2度に抑えています。3Dモードでは街を見る角度を45度にして、建物の側面と高さが見えるようにしています。

下のバーは **宇宙視点 → 上空への移動 → 下降 → 鑑賞 → 上昇** をまとめた1地点分です。各段階の切替ではリセットせず、次の地点に移る際だけ0に戻ります。一時停止中は止まり、速度を変更しても進捗の割合は維持します。

**宇宙視点 → 高度を保って目的地上空へ移動 → ランドマークへズームイン → ゆっくり周回 → 宇宙へズームアウト** を無限に繰り返します。街・建築と自然風景を交互に配置しています。

巡回先は **40か所**。市街地の代表座標ではなく、特徴的な建物・山頂・海岸線などを中心に据えています。建築は対象から約1.6〜7 km、広い山岳・島は約9〜26 kmの斜距離で鑑賞します。3D地形を使わない場合は地表の衛星画像を注視し、山頂の標高分だけ空中を見てしまうことを防ぎます。

### 操作

- `Space`: 一時停止 / 再開
- `←` / `→`: 前 / 次の場所
- `H`: UI 表示 / 非表示
- `S`: 設定
- `F`: 全画面

設定から、速度、描画解像度、フレームレート、シャッフル、地名情報、3D表示方式を調整できます。設定はこのブラウザの `localStorage` に保存されます。

### URL パラメータ

| パラメータ | 効果 |
|---|---|
| `wallpaper=1` | Lively Wallpaper向け。操作ボタンを隠し地球のマウス操作を無効化 |
| `ui=0` | HUDと進行バーを非表示 |
| `speed=1.5` | 巡回の速さ（0.5〜2） |
| `quality=0.65` | 描画解像度（0.5〜1） |
| `fps=24` | フレームレート（24/30/60） |
| `labels=0` | 地名・情報を非表示 |
| `shuffle=1` | 巡回順をシャッフル |

**省電力・HUDなしの例:** `?wallpaper=1&ui=0&fps=24&quality=0.65`

## 3D表示を有効にする

1. [Cesium ion](https://ion.cesium.com/)でアカウントを用意し、Google Photorealistic 3D Tilesを有効にします。
2. [Access Tokens](https://ion.cesium.com/tokens)で、そのデータを読み取れるトークンを作成します。Googleの3Dデータは **asset 2275207** です。公開URLを制限する場合は、このサイトのURLを許可してください。
3. 壁紙サイトの設定（`S`）で **「Google 写真ベース3D」** を選び、トークンを入力して「表示を適用」を押します。
4. 右上に **GOOGLE PHOTOREALISTIC 3D** と出ればデータへの接続が成功しています。細部のタイルはその後順次読み込まれます。

| 表示方式 | 内容 | 必要なデータ |
|---|---|---|
| Google 写真ベース3D（初期選択） | 写真の質感を持つ立体的な街・地形 | Google Photorealistic 3D Tiles |
| 3D地形＋OSM建物 | 起伏のある地形と簡略化された立体建物 | Cesium World Terrain（asset 1）とCesium OSM Buildings（asset 96188） |
| 衛星写真のみ | 地球に衛星写真を貼った軽量表示 | トークン不要 |

**トークン未設定の場合、実際の表示は衛星写真のままです。** 設定画面と右上にその状態を明示します。接続に失敗しても巡回を止めず、直前の表示を保ちます。Googleの詳細な3Dデータは全地点に同じ精度で収録されているわけではありません。

トークンは実行環境の `localStorage` に保存し、データ取得の認証に使用します。GitHubのソースコードやURLには含めません。通常のブラウザとLivelyは保存領域が異なるため、Livelyで使う場合はLively側でも設定してください。利用枠・料金はCesium ionで確認してください。チャットにトークンを貼る必要はありません。

## 動作と制限

- CesiumJS **1.147.0** を jsDelivr CDN から読み込みます。
- 衛星写真モードでは **Esri World Imagery** 公開サービスを利用します。接続できない場合は標準地図にフォールバックします。
- GoogleモードではGoogleの3D地表を表示し、Esriの地球面は非表示にして重なりを防ぎます。Cesiumが生成するデータ提供元の帰属表示を保持しています。
- インターネット接続・WebGL・GPUアクセラレーションが必要です。PCの負荷が気になる場合は `fps=24&quality=0.65` を推奨します。
- Cesium・地図データの帰属表示は削除しないでください。

## GitHub Pages 公開

1. 公開リポジトリを作成し、このフォルダのファイルをリポジトリ直下にアップロードします。
2. GitHub の `Settings → Pages → Build and deployment → GitHub Actions` を選択します。`.github/workflows/deploy.yml` により自動公開されます。
3. `https://<username>.github.io/<repo>/?wallpaper=1` を Lively Wallpaper に指定します。
