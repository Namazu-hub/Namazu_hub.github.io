# ATLAS — Earth in Motion

CesiumJS を使った、都市と大自然を繰り返し巡る **シネマティックな地球ライブ壁紙**です。Lively Wallpaper / Windows / 通常のブラウザに対応します。

## 使い方

### Web から（推奨）

GitHub Pages などの静的ホスティングで `index.html` を公開し、Lively Wallpaper の **「壁紙を追加」→「URLを入力」** に次の URL を指定します。

```
https://your-username.github.io/atlas-wallpaper/?wallpaper=1
```

`?wallpaper=1` では操作ボタンを隠し、マウスでの地球操作を無効にします。シーンは自動で続きます。

### ローカルで

フォルダ内で `python -m http.server 8000` を実行し、`http://localhost:8000/?wallpaper=1` を開いてください。ブラウザから `file://` で直接開くより HTTP サーバーを推奨します。インターネットへの接続は衛星画像と CesiumJS の読み込みに必要です。

## 再生仕様

**宇宙視点から地球を回転 → 次の目的地へズームイン → 目的地をゆっくり周回 → 宇宙へズームアウト → 次へ移動** を無限に繰り返します。都市と山岳・自然風景は交互に配置しています。

巡回先（初期順）: 東京、富士山、ニューヨーク、エベレスト、パリ、マッターホルン、シンガポール、グランドキャニオン、香港、キリマンジャロ、イスタンブール、マチュピチュ、ドバイ、アオラキ、ローマ、ケープタウン。

### 操作

- `Space`: 一時停止 / 再開
- `←` / `→`: 前 / 次の場所
- `H`: UI 表示 / 非表示
- `S`: 設定
- `F`: 全画面

設定から、速度、描画解像度、フレームレート、シャッフル、地名情報、3D地形を調整できます。設定はこのブラウザの `localStorage` に保存されます。

### URL パラメータ

| パラメータ | 効果 |
|---|---|
| `wallpaper=1` | Lively Wallpaper向け。操作ボタンを隠し地球のマウス操作を無効化 |
| `ui=0` | HUDと進行バーを非表示 |
| `speed=1.5` | 巡回の速さ（0.5〜2） |
| `quality=0.65` | 描画解像度（0.5〜1） |
| `fps=24` | フレームレート（24/30/60） |
| `labels=0` | 地名・情報を非表示 |
| `shuffle=1` | 巡回順をシャッフル |

**省電力・HUDなしの例:** `?wallpaper=1&ui=0&fps=24&quality=0.65`

## 3D 地形（山の立体感）

衛星写真と地形の高さは別のデータです。**トークンを設定しない場合は地表が楕円体のため、山は衛星画像として表示されますが、起伏は再現されません。**

Cesium ion の無料アカウント等でアクセストークンを取得し、トークンに **Cesium World Terrain (asset 1)** のアクセス権を設定すると、設定画面から有効にできます。トークンは実行環境の `localStorage` に保存し、GitHubのソースコードには書き込みません。公開端末・共有端末ではトークンの保管に注意してください。Cesium ion 側の利用条件・転送量・制限を確認してください。

## 動作と制限

- CesiumJS **1.147.0** を jsDelivr CDN から読み込みます。
- 通常は **Esri World Imagery** 公開サービスを利用します。接続できない場合は標準地図にフォールバックします。Esri などの提供条件と利用制限に従ってください。
- 地球上の都市の建物を立体モデルとして描画するわけではありません。表示は衛星画像、地形はオプションです。建物のフォトリアル3D化には別のデータ提供サービスと認証が必要です。
- インターネット接続・WebGL・GPUアクセラレーションが必要です。PCの負荷が気になる場合は `fps=24&quality=0.65` を推奨します。
- Cesium・地図データの帰属表示は削除しないでください。

## GitHub Pages 公開

1. 公開リポジトリを作成し、このフォルダのファイルをリポジトリ直下にアップロードします。
2. GitHub の `Settings → Pages → Build and deployment → Deploy from a branch` で `main` と `/ (root)` を選びます。
3. `https://<username>.github.io/<repo>/?wallpaper=1` を Lively Wallpaper に指定します。
